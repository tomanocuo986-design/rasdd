# دليل النشر والتشغيل المؤسسي لـ «رصد»

يغطي: الانتقال من الاستضافة المجانية، قاعدة البيانات المركزية المشفّرة، النموذج المحلي، وخطة التكامل مع أنظمة البلديات.

## 1) البنية

```
المتصفح (IndexedDB/localStorage: سرعة + عمل دون اتصال)
   │  HTTPS  +  Authorization: Bearer <رمز المدقق>
   ▼
خادم رصد (حاوية Node)  ──►  PostgreSQL   (الاسم والمحتوى مشفّران بـ AES-256-GCM على مستوى الحقل)
   │
   └─► نموذج لغوي: Ollama/vLLM داخل الشبكة  أو  Gemini
```

- العمل اليومي يبقى محليًا في المتصفح. «المزامنة» (تبويب النسخ الاحتياطي ← المزامنة مع قاعدة البيانات المركزية) تنسخ مساحة العمل للخادم، وتستعيدها على أي جهاز.
- التعارض: كل نسخة لها رقم إصدار. إن تغيّرت على الخادم من جهاز آخر يرفض الخادم الحفظ (409) ولا يستبدل شيئًا تلقائيًا؛ يختار المدقق الاستعادة أو الاستبدال.
- ملفات PDF الكبيرة لمكتبة الأنظمة لا تُزامَن؛ تبقى في النسخة الاحتياطية المشفّرة المحلية.

## 2) المتغيرات

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL. بدونه تُعطَّل المزامنة فقط. |
| `DATABASE_SSL=require` | لقواعد البيانات المُدارة (RDS / Azure). |
| `RASD_DATA_KEY` | مفتاح تشفير الحقول: `openssl rand -base64 32`. خزّنه في AWS KMS/Secrets Manager أو Azure Key Vault، **وليس** في نفس مكان نسخ قاعدة البيانات. |
| `RASD_DATA_KEY_PREV` | المفاتيح القديمة أثناء التدوير (مفصولة بفواصل). الكتابات الجديدة بالمفتاح الحالي والقديمة تبقى مقروءة. |
| `RASD_API_TOKENS` | `مدقق1:رمز,مدقق2:رمز` (الرمز 16 حرفًا فأكثر؛ يُفضّل 32+). اسم الرمز = مالك مساحة العمل، ولا يرى مدقق مساحة غيره. |
| `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY` | نموذج محلي متوافق مع OpenAI. يتقدّم على Gemini إن ضُبط. |
| `DOC_REVIEW_ALLOW_EXTERNAL` | `1` يسمح بمزود خارجي لمراجعة المستندات (ممنوع افتراضياً؛ انظر `DOC_REVIEW.ar.md`). |
| `GEMINI_API_KEY` | بديل سحابي. |

**الجلسات:** تُحفظ في الخادم (جدول `rasd_sessions` مع `DATABASE_URL`، أو `sessions.json` في `AUTH_DATA_DIR`). تسجيل الخروج وقرار المدير (`revoke-sessions`) يُبطلان الرمز فوراً، ويسقطها حذف الحساب. عند أول نشر لهذه النسخة يُطلب من الجميع إعادة تسجيل الدخول مرة واحدة. على Render بلا قاعدة بيانات تُمسح الملفات عند كل نشر فتنتهي الجلسات معها.

تدوير المفتاح: ضع المفتاح الجديد في `RASD_DATA_KEY` والقديم في `RASD_DATA_KEY_PREV`، أعد التشغيل. الصفوف تُعاد كتابتها بالمفتاح الجديد عند أول حفظ لها؛ لا تحذف المفتاح القديم قبل ذلك.

## 3) التشغيل

**داخل المؤسسة (On-Premises):** `cp .env.example .env` وعبّئه، ثم `docker compose up -d --build` (أضف `--profile local-llm` للنموذج المحلي، ثم `docker compose exec ollama ollama pull qwen2.5:7b-instruct` وضع `LLM_BASE_URL=http://ollama:11434/v1`). ضع وكيلًا عكسيًا (nginx/Caddy/IIS ARR) لإنهاء TLS.

**AWS:** صورة Docker ← ECR، ثم ECS Fargate (خدمة بعدد مهام ≥ 1 دائمًا) خلف ALB بمسار فحص `/api/health`، وRDS PostgreSQL مع `DATABASE_SSL=require`، والأسرار من Secrets Manager.

**Azure:** App Service for Containers (خطة Basic فأعلى مع **Always On**) أو Container Apps مع `minReplicas: 1`، وAzure Database for PostgreSQL، والأسرار من Key Vault. مسار الفحص `/api/health`.

**منع التوقف المفاجئ (Cold Start):** الاستضافات المجانية تُوقف الخدمة عند الخمول. الحل في الإنتاج: نسخة واحدة على الأقل تعمل دائمًا + فحص صحة دوري، لا مجرد تكبير الموارد.

## 4) الأداء

- استيراد CSV يُعالج على دفعات (5000 سجل) مع نسبة تقدّم، فلا تتجمد الواجهة. Excel/JSON/XML تُقرأ ثم تُطابَق كاملة (المحدد الفعلي لها حجم الملف في ذاكرة المتصفح).
- ملفات الواجهة المبنية (`/assets/*`) ذات أسماء مُجزّأة بالمحتوى: فعّل لها `Cache-Control: public, max-age=31536000, immutable` من الوكيل العكسي/ALB/CDN.

## 5) النسخ الاحتياطي

- **للمدقق:** تنزيل نسخة مشفّرة بكلمة مرور (AES-256-GCM + PBKDF2) وتذكير بعد 7 أيام دون نسخة. كلمة المرور لا تُحفظ في أي مكان؛ فقدانها يعني فقدان النسخة.
- **للخادم:** `pg_dump` دوري. الأعمدة مشفّرة أصلًا، لكن احفظ `RASD_DATA_KEY` بشكل منفصل وإلا لا تُستعاد البيانات.

## 6) ملاحظات أمنية

- `/api/chat` لا يتطلب رمز دخول (يحدّه معدّل الطلبات فقط). عند نشره خارج شبكة المؤسسة ضعه خلف VPN أو SSO من الوكيل العكسي.
- لا ترفع `.env` إلى Git. إن وُضع مفتاح Gemini في ملف مُشارك فاعتبره مكشوفًا وأعد إصداره.
- المسودات التي يولّدها النموذج تحتاج مراجعة المدقق؛ أرقام المواد تأتي فقط من `legal-articles.json` بعد المراجعة القانونية.

## 7) التكامل مع أنظمة البلديات (تدريجي)

1. **قائم الآن:** استيراد ملفات Excel / CSV / JSON / XML مع مطابقة ذكية لأسماء الأعمدة (عربي/إنجليزي، همزات، أرقام هندية) وتواريخ Excel، ورفض السجلات الخاطئة مع تقرير.
2. **التالي (لم يُنفَّذ):** موصّلات للقراءة فقط من قواعد ERP (حساب قاعدة بيانات للقراءة فقط + استعلامات معتمدة لكل جدول)، تُشغَّل كمهمة مجدولة على الخادم وتُدخل الصفوف عبر نفس مسار الاستيراد والتحقق. تُحدَّد بعد معرفة نوع النظام وصيغة جداوله في كل بلدية.

## الأدوار وسجل التدقيق والتسجيل (جديد)

**الأدوار**: `auditor` (مدقق، الافتراضي) — `reviewer` (مراجع: يقرأ سجل التدقيق) — `admin` (مدير: يدير الأدوار).
عيّن أول مدير ومراجع من البيئة (تتفوق على المخزَّن في قاعدة البيانات كي لا يُقفل المدير خارج النظام):

```
RASD_ADMINS=1001
RASD_REVIEWERS=2001,2002
```

**التسجيل**: `AUTH_REGISTRATION=open|invite|closed`. في الإنتاج استعمل `invite` مع `AUTH_INVITE_CODE` (رمز طويل عشوائي)
أو `closed` وأنشئ الحسابات بنفسك. الوضع `open` للتجارب فقط.

**سجل التدقيق** (`rasd_audit_log`): كل حدث (دخول، فشل دخول، تغيير دور، استخدام المساعد، مزامنة، اعتماد/رفض ملاحظة، تصدير تقرير،
تجاوز سند قانوني) يحمل بصمة SHA-256 تشمل بصمة الحدث السابق؛ أي تعديل أو حذف يكسر السلسلة ويكشفه التحقق.
مع PostgreSQL يمنع مشغّل قاعدة البيانات `UPDATE/DELETE`. لا يُسجَّل نص الملاحظات ولا بيانات التدقيق ولا كلمات المرور.

- قراءة السجل (مراجع/مدير): `GET /api/auth?audit=1&limit=200` ← `{ verify, total, events }` (`verify.ok=false` يعني أن السلسلة مكسورة).
- قائمة المستخدمين (مدير): `GET /api/auth?users=1`.
- تغيير دور (مدير): `POST /api/auth {"action":"set-role","employeeId":"1234","role":"reviewer"}`.
- بدون `DATABASE_URL` يُحفظ السجل في `data/audit-log.jsonl`، ويُمسح مع كل نشر على Render المجاني — **لا يصلح للإنتاج**.

**المساعد الذكي** صار يتطلب جلسة دخول (كان مفتوحًا لأي زائر ويستهلك مفتاح النموذج).

## البحث في مكتبة الأنظمة (RAG)

عند كل سؤال يبحث المتصفح في مكتبة الأنظمة المرفوعة (BM25 على نص عربي مطبّع) ويرسل أفضل 4–6 مقاطع مع السؤال.
يُلزَم النموذج بالاستشهاد بها فقط (اسم الوثيقة + رقم المادة كما ورد في المقطع)، وإلا يقول «لا يوجد سند كافٍ في المكتبة».
تظهر المصادر المستعملة تحت كل رد. ملاحظة خصوصية: مقاطع الأنظمة تُرسل إلى مزوّد النموذج (Gemini) كجزء من الطلب؛
اضبط `LLM_BASE_URL` لنموذج داخلي إن كان ذلك غير مقبول.
